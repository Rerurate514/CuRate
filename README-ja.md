# CuRate
## セットアップ手順
まず、このリポジトリをクローンします。
```sh
git clone https://github.com/Rerurate514/CuRate
```

そして、docker compose upするだけ！
```sh
docker compose up -d
```

## 設定
初回実行で、生成される.envには以下のような変数がセットされます。
```env
# windowsなら
DRIVE_PATH=C:\

# linux/macなら
DRIVE_PATH=/
```

これは実際にファイルが保存されるパスを指定します。
何も設定しない場合にはOSのプロジェクトルートが書き込まれ、そこにファイルとディレクトリが保存されていきます。

## 使い方
まず、初回起動時にsetup画面が開かれます。
ここで、ユーザネームとパスワードを設定してください。
忘れてもファイルはローカルにあるので、大丈夫です。

setupに成功すると、自動的にlogin画面へと遷移します。
そこで設定したユーザネームとパスワードを入力します。

loginに成功すると、/dashboard画面へと遷移します。
そこから使用する機能を選択します。

### Drive
Driveでは、envに設定したディレクトリにてフォルダとファイルを追加、ダウンロード、削除することができます。
